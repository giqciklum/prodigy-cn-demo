# Prodigy · Congelados de Navarra

Demostración conceptual de workflows, trazabilidad, aprobación humana y conocimiento con fuentes.

**Demo:** https://giqciklum.github.io/prodigy-cn-demo/

**Manual de presentación:** https://giqciklum.github.io/prodigy-cn-demo/manual-presentacion.pdf

**Copia sin conexión:** https://giqciklum.github.io/prodigy-cn-demo/demo-sin-conexion.zip

## Alcance

Todos los incidentes, lotes, registros, procedimientos y resultados son ficticios. Esta web independiente funciona en el navegador con lógica determinista. No ejecuta el backend de Prodigy, no contiene su código privado, no llama a modelos de IA y no conecta con SAP, MES, WMS ni sistemas de producción. No se envían correos.

El generador reconoce tres escenarios preparados. Las decisiones y workflows duran mientras permanezca abierta la página. Recargar o reiniciar borra ese estado. Los expedientes y registros se pueden descargar.

## Abrir sin instalación

Descarga la copia sin conexión, descomprime la carpeta y abre `index.html`. Las fuentes tipográficas tienen alternativa local si no hay Internet. Se recomienda una pantalla de portátil para presentar; la interfaz también se adapta a móvil.

## Contexto público

La sección «Por qué Prodigy» enlaza a la historia corporativa de Congelados de Navarra y a casos publicados por Mecalux y Planning Manufacturing. Esas referencias no implican conexión activa, validación ni adopción de este demostrador por parte de Congelados de Navarra.

## Verificación

Se ha probado creación de workflow, condición sin activación, espera de aprobación, rechazo sin retención, aprobación, balances de palés, traza de mezclas, descarga de expediente y registro, reclamación con lote desconocido, citas, ausencia de evidencia, calculadora, reinicio, parte diario y navegación móvil. No se pretende certificar ningún proceso industrial.
